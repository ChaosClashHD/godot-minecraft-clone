# Minecraft-like Prototype for Godot

This project is a compact Minecraft-inspired voxel prototype built in Godot 4.
It includes:

- first-person movement
- jumping and sprinting
- terrain generation
- block breaking and placing
- simple voxel mesh rendering
- raycast target selection

## Requirements

- Godot 4.2 or newer
- Import the project folder and run the main scene

## Controls

- W/A/S/D: move
- Shift: sprint
- Space: jump
- Mouse: look around
- Left click: break block
- Right click: place block
- Esc: release mouse cursor

## How to run

1. Open Godot 4.
2. Select Import.
3. Open this folder.
4. Press F5 or click Run.

## Notes

This is a lightweight prototype focused on the core loop and feel of block-based exploration rather than a full clone of Minecraft's advanced systems.
